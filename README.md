# Vastra Boutique 👗

## Local Business Website & Live Pitch Project

Vastra Boutique is a modern, responsive boutique website created as part of the Future Interns Full Stack Web Development Internship.

### 🌸 About the Project

The website is designed to give a local boutique a professional online presence and help customers explore collections, search products, interact with the shopping bag, and contact the business easily.

### ✨ Features

- Responsive design for desktop and mobile
- Modern boutique-style homepage
- Product collections
- Product search
- Category filtering
- Add to Bag functionality
- Favorite products
- Shopping bag modal
- Contact/enquiry form
- WhatsApp contact button
- Customer reviews
- Gallery section
- About the boutique section
- Special offers section
- Mobile navigation menu
- Back-to-top button
- Toast notifications
- Form validation

### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

### 🎯 Business Benefits

The website can help a local boutique:

- Build a professional online presence
- Showcase products to customers
- Make it easier for customers to contact the business
- Promote special offers and collections
- Improve customer engagement
- Reach more customers online
